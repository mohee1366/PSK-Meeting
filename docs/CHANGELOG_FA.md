# تغییرات نسخه‌ها

## نسخه 0.3.0 — نسخه آموزشی آفلاین
- افزودن حالت نمایشی آفلاین در اپلیکیشن اندروید با ورود آزمایشی `demo / 123456`.
- افزودن اتاق‌ها و رزروهای نمونه برای نمایش قابلیت‌ها بدون اتصال به سرور.
- رزرو و درخواست خدمات در حافظه موقت برنامه نگهداری می‌شوند و با بستن برنامه پایدار نمی‌مانند.
- QR در این نسخه صرفاً نمایشی است و برای کنترل ورود واقعی اعتبار ندارد.
- حالت اتصال به API واقعی با تنظیم `EXPO_PUBLIC_DEMO_MODE=false` حفظ شده است.

# تاریخچه تغییرات PSK Meeting Enterprise

## نسخه 0.2.4 — آماده‌سازی ورود کارکنان و مسیر ساخت APK

- فایل واقعی Excel با پسوند XLSX برای ورود کارکنان به مخزن وب اضافه شد.
- پنل مدیر به‌جای تولید CSV ناسازگار، فایل XLSX منطبق با API دانلود می‌کند.
- راهنمای ورود کارکنان با کدهای واقعی شعبه‌ها (`PSK-THR` و `PSK-KSH`) اصلاح شد.
- فایل قالب دارای دو برگه Employees و راهنما، توضیح ستون‌ها و فرمت Text برای کد پرسنلی و موبایل است.
- مسیر EAS برای ساخت APK با پروفایل Preview در پوشه اپ موبایل قرار گرفت.
- Workflow مستقل GitHub Actions برای ساخت APK با EAS اضافه شد؛ به توکن و شناسه پروژه متعلق به سازمان نیاز دارد.
- راهنمای اجرای فوری ۴۸ ساعته برای ورود کارکنان و ساخت APK اضافه شد.
- آزمون‌های ایستای پروژه به 24 مورد افزایش یافت.
