# نسخه آموزشی PSK Meeting 0.3.0

## هدف
این نسخه برای ارائه، تمرین و نمایش جریان‌های اصلی سامانه ساخته شده است و نسخه عملیاتی سازمان نیست.

## ورود نمایشی
- نام کاربری: `demo`
- رمز عبور: `123456`

## قابلیت‌های قابل نمایش
- مشاهده چهار اتاق نمونه در تهران و کاشان
- مشاهده یک رزرو نمونه تأییدشده
- ثبت رزرو آزمایشی و مشاهده وضعیت در انتظار تأیید
- ثبت درخواست خدمات (نظافت، پذیرایی و تعمیرات)
- نمایش QR نمایشی و شبیه‌سازی نتیجه اسکن

## محدودیت‌های آگاهانه
- داده‌ها در حافظه موقت برنامه هستند؛ با بسته‌شدن کامل برنامه پاک می‌شوند.
- هیچ اطلاعات واقعی کارکنان یا رزروهای سازمانی در این نسخه وجود ندارد.
- QR نمایشی است و نباید برای کنترل تردد استفاده شود.
- ارسال پیامک، احراز هویت واقعی و اتصال به پایگاه داده در حالت نمایشی انجام نمی‌شود.
- حالت نمایشی به‌صورت پیش‌فرض فعال است. برای اتصال به API واقعی باید `EXPO_PUBLIC_DEMO_MODE=false` و `EXPO_PUBLIC_API_URL` تنظیم شود و برنامه مجدداً ساخته شود.

## ساخت APK
پروفایل `preview` در `apps/mobile/eas.json` خروجی APK تولید می‌کند. ساخت APK به حساب Expo/EAS و اعتبارنامه build نیاز دارد.
